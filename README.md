# Enterprise Windows Lab

## Overview

This repository documents the design, deployment, and administration of an enterprise Windows Server environment built in a home lab using Proxmox Virtual Environment (VE).

The goal of this project is to gain practical experience with enterprise Windows infrastructure while building a professional portfolio that demonstrates system administration, troubleshooting, and documentation skills.

The environment simulates a small business network and includes Active Directory, DNS, DHCP, file services, Group Policy, IIS, and Windows client management.

---

## Objectives

- Design an enterprise-style Windows infrastructure.
- Deploy Active Directory Domain Services (AD DS).
- Configure DNS and DHCP.
- Join Windows clients to the domain.
- Implement file sharing using SMB and NTFS permissions.
- Configure Group Policy.
- Automate administrative tasks with PowerShell.
- Document implementation, testing, and troubleshooting.

---

## Lab Environment

| Component | Technology |
|----------|------------|
| Hypervisor | Proxmox VE |
| Domain Controller | Windows Server 2022 |
| Client | Windows 11 |
| Linux Server | Rocky Linux 9 |
